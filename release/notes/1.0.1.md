修一个影响手感的 bug：**睡着以后她再也醒不过来**。

A bug-fix release: **once the pet fell asleep it could not be woken up.**

## 修了什么 / Fixed

睡眠状态没有被任何交互清掉，`sleeping` 标记一旦置位就一直为真，而点击、拖拽、情境规则的入口都写着
`if (sleeping) return;` —— 于是——

- 点她：台词照说，但动作不切，一直循环睡姿
- 拖她：能拎起来，松手后卡在"悬空"循环里（因为 `sleeping` 还是 true，落下的收尾动画被跳过）
- 只有"喂食"能救回来（它会顺带重置入睡计时）

现在凡是主动交互都会叫醒她，并顺手清掉"被拎起"的姿态：

| 交互 | 之前 | 现在 |
| --- | --- | --- |
| 点一下 | 无反应 | 醒来 + 播分区反应 |
| 拖拽 | 卡在悬空循环 | 醒来 + 拎起 + 落下回待机 |
| 打开对话框 | 继续睡 | 醒来 |
| 喂食 | 能醒 | 能醒（不变） |

站点信号（情境规则、选中文字）现在**不会**把她吵醒——只有你动手才算数。

## 改动 / Changes

- `js/pet/index.js`
  - 导演新增 `wake({ silent })`，`cue()` / `hold()` 在睡眠时先静默唤醒
  - `cue()` 顺带清掉上一次点击残留的 `holding`（拖拽中不清，否则接不上悬空）
  - `doPet()` 点击后重置入睡计时；`setChatOpen(true)` 也算一次交互
  - `sleep()` 在拖拽/聊天中不触发
  - `runContext()` / `watchSelection()` 跳过睡眠中的情境反应
  - `PetDebug[hostId]` 暴露 `director` / `player`，方便复现这类问题

其余文件与 v1.0.0 完全一致。
