# 桌宠工具集 v1.0.4

这一版四件事：**所有配置都能在界面里改**、**双击打开也能用**、**多只宠物能在一份配置里管**、
**文档不再绑死某个角色名**。

Four things in this release: every setting is reachable from the UI, the archive works when
opened by double-click, several pets can live in one config file, and the docs no longer
assume a particular character.

## 一、配置项全部可见 / Every setting has a home

`config/pet.yaml` 的 24 个顶层键现在都有界面入口：

- 新增「界面」分组：按钮收起宽限、淡入淡出时长、阅读速度（`ui.*`）
- 「外观」补上立绘框宽高、三个主题色、动画格式（`size` / `accent` / `clipExt`）
- 「状态」面板本来就有，这次确认可用（每个状态的动画、池、权重、循环区间）

新增 **`docs/CONFIG.md`**（另有英文版）：逐项列出 46 个键的含义、默认值、去哪个页面改。
清单与代码共用一份源（`assets/vars.js`），`tools/check-config-doc.js` 三方对账，
发版时自动执行——文档漏写会让构建失败。

## 二、双击就能打开 / Works on double-click

之前发行包的 `demo.html` 用的是 `/css/...` 绝对路径，双击后样式 404，看着像坏了。

- 改为相对路径，`file://` 下正常加载
- 打包校验新增一条：发行包任何页面都不许出现根路径引用，出现就让构建失败
- 发行根目录新增 **`如何打开.txt`**：讲清楚「双击只能看」「双击 start.bat 才能存」

## 三、一份配置管多只宠物 / Several pets, one file

`config/pet.yaml` 支持合集形态：

```yaml
version: 1
active: whale
pets:
  - id: whale
    name: 小鲸
    config: { name: 小鲸, animDir: /images/pet/anim/ }
  - id: cat
    name: 小橘
    config: { name: 小橘, animDir: /images/pet/cat/ }
```

- 配置编辑器顶部出现「编辑哪一只」，来回切不丢改动
- 分区 / 规则 / 文案保存时只写回选中的那一只
- 编译只产出 `active` 那只，运行时无感
- 老的单只文件不用改，继续能用

## 四、文档不再绑死角色名 / No hard-coded character

README、STATUS、发行说明、首页副标题、示例变量值里的「大肥鱼」全部换掉，改成
「桌宠工具集」「示例角色」「小鲸」这类中性说法。角色数据仍在 `config/pet.yaml` 里，
换名字只改配置。

> 修一处事故：上一轮清洗时把 `js/pet/index.js` 的兜底默认名写坏成了
> `name: value='名称 A'`，会让没有站点配置的页面直接抛 `ReferenceError`。已修好并加进验证流程。

## 升级 / Upgrading

博客侧：替换 `js/pet/`、`css/`、`images/pet/` 三样即可，配置不需要动。
配置文件的两种形态都向后兼容。

Replace `js/pet/`, `css/` and `images/pet/` on the blog side. Both config shapes stay compatible.
