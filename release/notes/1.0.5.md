# 桌宠工具集 v1.0.5

这一版四件事：**界面完整中英双语**、**不再依赖 Python 起服务**、**修掉两个真 bug**。

Four things: fully bilingual UI, a Python-free local server, and two real bug fixes.

## 一、界面全部中英双语 / Fully bilingual UI

之前多数新增文案只写了中文，切到英文后仍是中文。这次补齐：

- 配置 / 分区 / 规则 / 文案 / 演示 / 变量表 / 文档 / 测试 **八个页面**
- 字典条目从 228 条扩到 **809 条**
- 新增 `tools/check-i18n.js`：扫描页面里没走 i18n 的中文，**漏一条就发版失败**

实测：切到英文后，八个页面残留中文全部清零（语言切换按钮的「中文」和宠物自己的台词属于内容，不算漏翻）。

## 二、不依赖 Python 的本地服务 / Python-free local server

以前 `start.bat` 要求装 Python。现在换成**纯 Node 单文件服务**：

```
server.js    零第三方依赖，一个文件跑完
start.bat    Windows 双击
start.sh     macOS / Linux
```

- 需要 Node.js 18+（没有会在窗口里给出下载地址）
- 端口占用自动顺延 8080 → 8081 …
- 接口与旧版一一对应：`/api/version` `/api/assets` `/api/backups` `/api/save` `/api/patch` `/api/restore` `/api/build`

## 三、两个真 bug / Two real fixes

**1. 本地服务目录边界判断错误**

`server.js` 用 `target.indexOf(ROOT) !== 0` 判越界，Windows 下大小写与分隔符不一致，导致**所有静态文件都返回 403**。已改成归一化后比较。

**2. 规则编辑器「启用」折行**

`.en` 是 `inline-flex` 且没有 `nowrap`，窄容器里「启用」被拆成两行。已修，中英文都是单行 19px。

## 四、测速面板可收起 / Collapsible test panel

以前点「收起」只是加了个 `is-open` 类，而**这个类没有任何 CSS**，所以点了没反应。

现在收起后只留标题条（505px → 53px），按钮在「收起 / 展开」之间切换，英文下显示 Collapse / Expand。

## 升级 / Upgrading

博客侧不需要动，只替换 `js/pet/`、`css/`、`images/pet/`。
本地工具用的话，删掉旧的 `start.bat`，用新的 `server.js` + `start.bat` / `start.sh`，不再需要 Python。

The blog side is unchanged. For local tooling, replace the old `start.bat` with the new Node server — Python is no longer required.
