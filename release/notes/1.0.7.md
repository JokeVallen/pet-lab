# 桌宠工具集 v1.0.7

修一个使用体验问题：**通过 start.bat 打开，却提示「未连接本地服务」**。

## 问题

配置编辑器和规则编辑器打开时弹出提示条，说没连上本地服务——但服务明明是起的，
地址栏也是 `http://127.0.0.1:8080/`。

排查结果：服务端没问题，`HEAD /api/version` 稳定返回 200。问题在**探活太脆弱**：

原来的探活只发一次 `HEAD` 请求，一次失败就判定「没有服务」并弹提示。
但 `HEAD` 请求可能落在一条正在关闭的 keep-alive 连接上，
或者撞上服务刚启动、还没完全就绪的瞬间——这都会误报。

## 改法

探活改成「重试 + 回退」：

```
HEAD → 等 150ms → HEAD → 等 150ms → GET → 等 300ms → GET
```

四次全部失败才认定没有服务。同时提示条现在会**带上具体原因**，
例如 `(HTTP GET 未返回成功)`，以后真出问题截图就能定位。

## 验证

- 有本地服务：配置/分区/规则/文案四个编辑器均**不弹提示**
- 只有静态服务（没有 `/api`）：正常弹提示，并显示 `(HTTP GET 未返回成功)`
- 十个页面零运行时异常

## 升级

覆盖即可，博客侧不需要动。
