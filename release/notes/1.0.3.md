# 大肥鱼 · 博客桌宠 v1.0.3

一次文档更新：把「博客侧怎么对接宠物」写清楚了，并收进仓库。

A documentation release: how the blog side should integrate the pet is now written down and shipped
in the repository.

## 新增 / Added

**`docs/BLOG_INTEGRATION.md`**（另有 `.en.md`）——写给维护博客的人或 AI 的对接手册：

- **唯一来源**：只从 Release 取发行包，不碰 `main` 分支
- **目标形态**：`source/js/pet/`、`source/css/deepseek-pet.css`、`source/images/pet/` 三处固定位置，
  `config/pet.yaml` 永远是博客自己的
- **首次接入**：带版本号的加载片段（pjax 也覆盖），样式引入，构建命令
- **更新**：先删后拷（模块名会变，原地覆盖留死文件），只在该换时换素材，改版本号
- **硬性禁止**：改 `js/pet/` 内任何文件、用发行包的配置覆盖博客的、直接操作宠物 DOM
- **验证**：两条控制台命令 + 网络面板不得有 4xx
- **排查表**：不显示 / 空白 / 更新无效 / 出现两只 / 文案旧名字 / 样式全丢
- **站点能力**：`window.SiteAPI` 的模块清单、两层加载、权限分级、无 SiteAPI 时的降级范围
- **配置归属**：`config/pet.yaml` 归博客，`js/pet/config.js` 是生成物，其余谁都不改

## 顺带 / Also

- `docs.html` 侧栏新增「接入博客」，中英文档都能直接在页面里读
- README 页面表指向这份文档

## 升级 / Upgrading

本版只动文档，运行时与 1.0.2 完全一致。博客侧**不需要**做任何更新。

Runtime code is identical to 1.0.2. No action needed on the blog side.
