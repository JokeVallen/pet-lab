一只住在网页角落的鲸鱼娘：透明视频立绘、分区点击反应、状态随机、情境台词、站内检索。
纯前端，不接任何 API，不需要 Key。

A blog pet that lives in the corner of the page — transparent video, per-zone click reactions,
state-driven idling, contextual lines and site search. Pure front-end, no API, no key.

## 这个版本包含什么 / What's in this release

- **运行时 / runtime**：`js/pet/`（ES 模块，入口 `index.js`），无构建步骤、无依赖
- **素材 / artwork**：33 个带 alpha 的 VP9 WebM 片段 + `poster.webp` 首帧，共 4.6 MB
- **配置 / config**：`config/pet.yaml` + 生成的 `js/pet/config.js`，含 YAML 编译器
  `tools/build-config.js`（自带 js-yaml，免 `npm install`）
- **许可 / license**：代码 MIT、素材 CC BY-NC-SA 4.0，含完整署名与逐文件映射

**这个标签与压缩包只含发行内容**：没有开发服务器、可视化编辑器、测试与探针脚本、开发笔记。
需要这些请用 `main` 分支。

This tag and archive contain the **distribution only** — no dev server, visual editors, tests, probe
scripts or development notes. Those live on `main`.

## 装到博客 / Install

把 `js/pet/` 复制到 `source/js/pet/`、`css/deepseek-pet.css` 到 `source/css/`、`images/pet/` 到
`source/images/pet/`，然后加载模块：

```js
(function () {
    function ensurePet() {
        if (document.querySelector('script[data-pet-module]')) return;
        var s = document.createElement('script');
        s.type = 'module';
        s.src = '/js/pet/index.js';
        s.dataset.petModule = '1';
        document.body.appendChild(s);
    }
    if (document.readyState === 'loading') document.addEventListener('DOMContentLoaded', ensurePet);
    else ensurePet();
    document.addEventListener('pjax:complete', ensurePet);   // 主题开 pjax 时
})();
```

## 改配置 / Configure

```bash
node tools/build-config.js      # config/pet.yaml → js/pet/config.js
```

也可以直接编辑 `js/pet/config.js`（两者择一，别混着改）。角色名、台词、配色、尺寸、素材目录、
状态、分区、情境规则全部在配置里 —— 换一只宠物不用改代码，详见包内 `README.md`。
