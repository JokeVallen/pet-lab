# 桌宠工具集 v1.0.6

修 v1.0.5 引入的一个致命错误。

## 修掉了什么

**四个编辑器打开就白屏**

v1.0.5 做双语时，我把界面文案包进了 `T()`，但 `T` 的声明在脚本中段，
而 `SCHEMA` 表在脚本更前面就调用了它。这是 JavaScript 的暂时性死区（TDZ），
整页脚本直接中止。

```
Uncaught ReferenceError: Cannot access 'T' before initialization
```

**受影响的页面一共 4 个**：配置、分区、规则、文案编辑器。现在全部把 `T` 提到脚本第一行。

另外修了配置页「身份」那段说明：拼接串只有最后一句包了 `T()`，
前半句和「文案编辑」链接文字在英文界面下仍是中文。已改为整句走字典。

## 为什么会漏

我之前的检查只做了**语法检查**（能不能解析），语法正确不代表运行时不报错。

现在加了运行时探针：用无头浏览器逐页打开，监听 `Runtime.exceptionThrown` 和
`Log.entryAdded`，**任何页面有运行时异常都会被抓出来**。

## 验证

- 十个页面（含开发页）零运行时异常
- 八个页面切换中英文，界面文案残留 0 条
- 配置清单、配置文件、文档三者一致
- 发行包内实测：文档页正文正常渲染，编辑器可用
