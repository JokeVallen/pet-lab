两只宠物同页

右下角有两只：大肥鱼（默认配置）和 小橘（profile）。它们各自有独立的挂载点、 storageKey、位置、尺寸、配色和人设——共用同一份代码。

页面本身不 import 任何东西，只是先写好 window.PetProfiles，再插入两个带 ?pet= 参数的模块。不同 URL 的模块会被浏览器当成独立实例求值，所以各自一份状态。 

<script>
window.PetProfiles = {
  cat: {
    hostId: 'pet-cat',
    storageKey: 'pet-cat-v1',
    offset: { x: 172 },
    size: { width: 150, height: 133 },
    accent: { primary: '#f08a3c', primary2: '#e2603a', cyan: '#ffd08a' },
    persona: { name: '小橘', about: '……', feed: ['……'] },
    states: { idle: { clip: 'sad', pool: ['sad'] }, … }
  }
};
</script>
<script type="module" src="/js/pet/index.js"></script>
<script type="module" src="/js/pet/index.js?pet=cat"></script>

小橘没有自己的素材，所以它的 states 指到了现成的几段小动画（sad / doze / think）。换素材时把 animDir 指向新目录即可。
